Implement Stack using Single Queue

Problem Statement: Implement a Stack using a single Queue.

Note: Stack follows Last In First Out (LIFO) rule. Queue follows First In First Out (FIFO) rule.

Example:

  Explanation:
  push(): Insert the element in the stack.
  pop(): Remove and return the topmost element of the stack.
  top(): Return the topmost element of the stack
  size(): Return the size of the stack

Intuition

Stack returns the most recently inserted element. Queue returns the earliest inserted element.

To simulate a stack using a queue, we rearrange the queue on every insert so that the last inserted element always comes first.

Approach

  • Take a single queue.
  • push(x): Add element to queue. Then rotate all previous elements behind the new one.
  • pop(): Simply dequeue from the front.
  • top(): Peek the front element.
  • size(): Return queue size.

Repeat step 2 on every insertion to maintain LIFO behavior.

Code (C++)

#include<bits/stdc++.h>
  using namespace std;
  class Stack {
   queue<int> q;
  public:
   void Push(int x) {
     int s = q.size();
     q.push(x);
     for (int i = 0; i < s; i++) {
       q.push(q.front());
       q.pop();
     }
   }
   int Pop() {
     int n = q.front();
     q.pop();
     return n;
   }
   int Top() {
     return q.front();
   }
   int Size() {
     return q.size();
   }
  };
  int main() {
   Stack s;
   s.Push(3);
   s.Push(2);
   s.Push(4);
   s.Push(1);
   cout << "Top: " << s.Top() << endl;
   cout << "Size before: " << s.Size() << endl;
   cout << "Popped: " << s.Pop() << endl;
   cout << "Top after: " << s.Top() << endl;
   cout << "Size after: " << s.Size();
  }

Output:

Top: 1
Size before: 4
Popped: 1
Top after: 4
Size after: 3

Time Complexity: O(N)

Space Complexity: O(N)
